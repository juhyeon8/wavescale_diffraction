## 2. 요구사항

### 2-1. 화면 캡처 버튼 (용량 조절 가능)

- 컨트롤 패널 최상단(또는 헤더 우측)에 **"이미지 저장(PNG)"** 버튼 그룹을 추가한다.
- **캡처 대상은 패널①·②·③을 각각 개별 이미지로 저장한다.** 논문에는 그림별로 따로 삽입하므로, ①(메인 뷰)·②(위상자 방향)·③(Cornu 나선)마다 **독립된 저장 버튼**을 둔다. ("①·②·③ 개별 저장" 버튼 3개, 또는 각 패널 우상단에 작은 저장 아이콘 버튼)
- (선택) 3장을 한 번에 내려받는 "모두 저장" 버튼을 추가로 둬도 좋지만, **기본은 개별 저장**이다.
- **용량(해상도) 프리셋**을 여러 단계로 제공한다. `devicePixelRatio` 배율을 곱해 오프스크린 캔버스에 다시 렌더하는 방식으로 구현한다:
  - **저용량 (1×, 웹 미리보기용)**
  - **표준 (2×)**
  - **고해상도 (3×, 학회지 인쇄 기본)**
  - **초고해상도 (4×, 큰 지면/포스터용)**
- 추가로 **JPEG 품질 슬라이더(0.5~1.0)** 또는 "PNG / JPEG" 선택을 두어, 저용량이 필요할 때 JPEG + 낮은 품질로도 저장할 수 있게 한다.
- 파일명은 자동 생성하되 **어느 패널인지 + 현재 파라미터 + 배율**을 포함할 것. 예:
  `panel1_main_lambda500nm_a1mm_z1m_3x.png`
  `panel2_arrows_lambda500nm_a1mm_z1m_3x.png`
  `panel3_cornu_lambda500nm_a1mm_z1m_3x.png`
  (패널 번호·λ·a·z·배율을 파일명에 반영 → 논문 그림 정리에 유리)
- 구현 힌트:
  - 캔버스는 이미 `mainCanvas`(①) / `arrowsCanvas`(②) / `phasorCanvas`(③) 로 **이미 분리**되어 있으므로, 각각 그대로 개별 저장하면 된다.
  - 저장 함수는 `(canvas, panelName)` 를 받아 배율·포맷·품질을 적용하는 **공통 함수 하나**로 만들고, 버튼 3개가 각 캔버스를 넘겨 호출하게 한다.
  - 고배율 저장은 임시 캔버스를 `width = 원본 * scale` 로 만들고, 저장 시점에만 해당 패널을 그 배율로 다시 그리는 별도 렌더 경로를 만든다. (화면 표시용 렌더는 건드리지 않음)
  - `canvas.toBlob(cb, 'image/png')` 또는 `'image/jpeg', quality` 사용, `URL.createObjectURL` → `<a download>` 로 저장.

### 2-2. 배경 흰색 (인쇄/논문용 라이트 테마)

- `paper.css` 에서 배경과 색을 **인쇄용 밝은 테마**로 교체한다:
  - `body` 배경: `#0f1320` → **`#ffffff`**
  - 캔버스 배경(`.panel canvas` 의 `#0a0e1c`): **`#ffffff`** (또는 아주 옅은 `#fafafa`)
  - 패널/컨트롤 배경(`#161b2e`), 텍스트 색(`#e8ebf5`) 등도 **흰 배경에서 대비가 충분한 어두운 글자색**으로 조정.
- **중요:** `script.js`(→`paper.js`) 내부에 하드코딩된 캔버스 그리기 색들도 흰 배경 기준으로 다시 잡아야 한다. 흰 배경에서 안 보이거나 대비가 약한 것들:
  - 텍스트: `#aab2cf`, `#7a90c8`, `#7a8ab0`, `#e8ebf5` → **검정/진회색 계열**로.
  - ruler 눈금선 `rgba(255,255,255,0.15)`, 그림자 경계 점선 `rgba(255,255,255,0.25)` → **`rgba(0,0,0,…)`** 계열로.
  - 밝기 곡선 채움 `rgba(255,212,121,0.12)` 등 노란색 계열은 흰 배경에서 흐리므로 **진한 주황/검정 윤곽**으로 대비 강화.
  - 입사 평면파 선 `rgba(120,170,255,0.55)` → 흰 배경에서 보이도록 채도/명도 조정.
  - 색 띠(파랑→빨강 hsl 매핑, `yToColor`)는 의미가 있으므로 **유지하되**, 흰 배경에서 노란 계열(중간 hue)이 안 보이면 명도(`55%`)를 낮춰(`45%` 등) 대비를 확보.
- 색 하드코딩이 여러 함수에 흩어져 있으므로, `paper.js` 상단에 **테마 색상 상수 객체**(예: `const THEME = { text:'#111', axis:'rgba(0,0,0,0.3)', wave:'#3366cc', … }`)를 만들고 각 그리기 함수가 이 상수를 참조하도록 리팩터링하는 것을 권장. (단, 물리 엔진 함수는 제외)

### 2-3. 숫자 폰트 크게 (학회지 축소 대비)

- 논문에 이미지가 **축소 삽입**되어도 판독 가능해야 하므로, 시뮬레이션 안에 그려지는 **모든 수치·라벨 폰트를 키운다.**
- `paper.js` 안 `ctx.font = '11px sans-serif'` / `'10px'` / `'12px'` 로 하드코딩된 부분들을 **일괄 상향**한다:
  - 축 눈금(ruler) 라벨: `10px` → **최소 15~16px**
  - 장애물/평면파/②범위 등 캔버스 내 라벨: `11px` → **15~16px**
  - `|합|`, `상대 세기 I/I₀` 등 결과 수치: `12px` → **16~18px, bold**
  - 컨트롤 패널의 readout(λ, a, z 값 표시)과 스케일 정보 표(`#scale-table`): CSS에서 `font-size` 를 현재보다 **1.3~1.5배** 키움.
- **전역 폰트 배율 슬라이더**(예: 0.8×~2.0×)를 하나 추가해서, 캡처 전에 그림 크기에 맞게 라벨 크기를 미세 조정할 수 있게 하면 가장 편함. 내부적으로 `ctx.font` 의 px 값에 배율을 곱하는 헬퍼(`fontPx(base)`)를 만들어 모든 `ctx.font` 호출을 통과시킨다.
- 폰트를 키우면 라벨이 겹치거나 캔버스 밖으로 나갈 수 있으니, ruler 라벨 위치·장애물 라벨 위치 등의 좌표 여백을 함께 조정하고 Playwright 스크린샷으로 겹침을 확인한다.

### 2-4. 파장·장애물 크기 직접 입력창

- λ(파장), a(장애물 폭), z(거리)에 대해 **숫자 입력창(number input) + 단위 선택**을 추가한다. 기존 로그 슬라이더는 그대로 두고, 그 옆/아래에 정밀 입력 필드를 병행 배치.
  - 각 값마다: `<input type="number">` + 단위 드롭다운(`nm / µm / mm / cm / m`).
  - 입력 → SI(m) 변환 → `state.lambda/a/z` 에 대입 → 슬라이더 위치 동기화(`valueToSlider`) → `updateReadouts()` → `scheduleRecompute(0)` 호출.
  - 값이 `RANGES` 범위를 벗어나면 clamp하고 입력창에 실제 적용값을 되돌려 표시.
- 슬라이더를 움직이면 입력창 숫자도 갱신되도록 **양방향 동기화**한다. (`onParamChange` 안에서 입력 필드 값도 업데이트)
- 참고: 기존 코드에 이미 `formatLength`, `valueToSlider`, `sliderToValue`, `RANGES` 가 있으므로 이를 재사용한다.
