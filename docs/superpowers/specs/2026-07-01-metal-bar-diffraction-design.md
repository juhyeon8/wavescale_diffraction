## 0. 한 줄 요약

도선을 세로로 촘촘히 쌓아 **하나의 금속 막대(장애물)**를 만들고, 평면파를 입사시켜
**입사파 + 산란파의 중첩**으로 **파장에 따라 회절이 어떻게 달라지는지**, 그리고
**스크린에 맺히는 빛의 세기**를 한 화면에서 보여준다. 전자기파 중 **전기장 한 성분**만 그린다.

---

## 1. 개념 · 물리 모델

- **장애물**: x=0 위치에 세로로 쌓인 도선 N개 한 줄. 막대 높이 H ≈ (N−1)·d.
  - 간격 d가 줄고 굵기 2a가 커져 **2a ≥ d**가 되면 도선이 서로 겹쳐 **솔리드 막대**가 된다.
    이때 화면에 **"닿음(솔리드)" 배지**를 표시한다.
- **물리 모델**: 2D 스칼라 회절. 전기장이 도선과 평행(E∥wire, 화면 밖 방향)인 TM 편광.
  → 전기장이 단일 성분이라 깔끔하며, **이 한 성분만** 색지도로 그린다.
- **풀이(재사용)**: 기존 *유한 배열 MoM(모멘트법)* 을 그대로 재사용한다.
  - 각 도선 n에 유도전류 계수 c_n.
  - 산란장 E_scat = Σ_n c_n · H₀(k·ρ_n)  (H₀ = J₀ + iY₀, 바깥으로 퍼지는 원통파).
  - 경계조건: 각 도선 표면에서 E_total = 0 (완전 도체) → 선형계 Z·c = b, b_m = −1.
  - 이미 검증된 베셀/한켈 근사 · 복소 가우스 소거를 그대로 사용.
- **장(場) 정의**:
  - E_inc = 왼→오른 평면파 = exp(i·k·x)
  - E_scat = 도선들의 원통파 합
  - E_total = E_inc + E_scat

### 1.1 시간 규약 / 외향 한켈 (작업 전 검증 완료, 추측 아님)

기존 `script.js` 코드 근거로 확인한 규약 — **새 코드도 동일하게 유지한다**.

- **시간 규약: `e^{−iωt}`**
  - 근거: `drawFrame()`에서 `val = fr·cos(phase) + fi·sin(phase) = Re[E·exp(−i·phase)]`,
    `phase`가 시간에 따라 증가 → `phase = ωt` → 시간 인자 `exp(−iωt)`.
- **외향 한켈: `H₀⁽¹⁾(x) = J₀(x) + i·Y₀(x)`**
  - 근거: `hankel0(x) = { re: J0, im: Y0 }`; MoM의 Z행렬·산란장 모두 `J₀ + iY₀` 사용.
- **입사파: `exp(+ikx)`** (근거: `incRe=cos(kx), incIm=sin(kx)`).
- **일관성**: `exp(+ikx)·exp(−iωt) = exp(i(kx−ωt))` → +x 진행 ✅.
  `H₀⁽¹⁾(kr)·exp(−iωt) = exp(i(kr−ωt))` → 바깥으로 퍼지는 외향파 ✅.
- 유한 배열 MoM을 재사용하므로 **부호 변경 불필요**.

## 2. 화면 구성

- 왼쪽에 **세로 3칸** 색지도(가로 = 진행방향 x, 세로 = y):
  - ① 입사파
  - ② 산란파
  - ③ 중첩 (입사 + 산란)
  - 세 칸은 같은 색 스케일 → 눈으로 ①+②=③ 확인 가능.
- **③칸 오른쪽에 스크린 세기 곡선** I(y) = |E_total|²:
  - 세로 곡선으로 그리며, **y축을 장(場)의 y축과 공유** → "이 높이에서 얼마나 밝은가"가 직관적.
- **스크린 위치**: 막대에서 거리 L 지점에 세로 점선으로 표시(세 칸 모두).
  - **거리 L을 키우면 장의 가로범위가 스크린까지 함께 늘어나** 전체가 축소돼 보인다.
    (스크린이 항상 화면 안에 보이도록 하기 위함 — 합의된 동작.)
- 색: 빨강(+E) · 흰(0) · 파랑(−E). (기존 색 매핑 유지)

## 3. 조절 변수 (슬라이더)

| 변수 | 의미 | 범위 / 비고 |
|---|---|---|
| 도선 개수 N | 막대 높이 결정 | 2 ~ 120 (성능 상한) |
| 간격 d | **도선 중심 간 거리** | 작을수록 촘촘 |
| 굵기 a | 도선 반지름 | **2a ≥ d면 "닿음(솔리드)"** 표시 |
| 파장 λ | 입사파 파장 | 1 ~ 30 cm |
| 스크린 거리 L | 막대 → 스크린 | 회절 무늬 변화의 핵심 변수 |
| 진폭 A | 표시용 진폭 | 기존 유지 |

- 재생 / 일시정지 버튼 + 위상 슬라이더(정지 시 탐색) 유지.

**항상 화면에 병기하는 수치(슬라이더 아님)**:
- **λ/d 비** — 회절/투과 해석의 핵심 지표(아래 §5.1).
- **막대 높이 H = (N−1)·d** — 현재 장애물 크기.

## 4. 기존에서 덜어낼 것

- **"무한 배열(Floquet) 탭" 제거** — 유한 막대 한 실험에 집중 → **탭 구조 없는 단일 화면**.
- **"E⊥wire(수직 편광) 정성 토글" 제거** — E∥ 한 성분만 다룬다.
- **반지름 상한 `min(a, 0.3·d)` 제거** → 도선이 닿을 수 있도록 허용(대신 "닿음" 표시로 안내).

## 5. 계산 · 성능 · 물리적 한계

- N×N 복소 선형계를 매번 풀어 **O(N³)** → **N 상한 120**, 입력은 디바운스(기존 60ms) 유지.
- **도선이 닿는 순간부터(2a ≥ d)**: 얇은-도선 모델이 엄밀하지 않다.
  → 그 구간은 **"경향(정성적)"** 으로 해석한다.
    솔리드 막대의 회절 경향(파장 ↑ 일수록 그림자 영역에 빛이 더 차오름)은 충분히 잘 보여준다.
- **회절 무늬는 거리 L에 따라 성격이 바뀐다**:
  - L 작음 → 프레넬(근접장): 복잡한 줄무늬.
  - L 큼 → 프라운호퍼(원거리장): 부드러운 봉우리.
  - 이는 버그가 아니라 물리 현상 — 화면 안내문에 한 줄로 명시.

---

## 5.1 회절(가장자리) vs 투과(도선 틈 누설) 분리 — 가드레일 (블로커)

막대 뒤로 빛이 도는 데에는 두 원인이 섞일 수 있다:
**(a) 가장자리 회절**(막대 위·아래 끝을 돌아 들어옴) 과
**(b) 도선 틈 투과**(간격 d 사이로 새어 들어옴). 파장별 "회절" 비교가 투과로 오염되지
않도록 다음을 강제한다.

- **λ/d 비를 UI에 항상 표시**한다.
- **λ < 5d 이면 "투과 영향 구간" 경고 배지**를 띄운다.
  (틈 사이 누설이 무시 못 할 수준 → 순수 회절 비교 부적합 신호.)
- **파장별 회절 비교의 기준 시나리오는 "닿음(솔리드)" 상태**임을 안내문에 명시한다.
  (틈이 닫힌 솔리드 막대라야 투과 성분이 사라져 가장자리 회절만 비교 가능.)
